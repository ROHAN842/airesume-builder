## Yes — that is a valid and practical scoring approach

Your formula is the right kind of field-level evaluation for this extraction problem:

- each field in the ground truth gets a score
- 1 = exact or accepted equivalent match
- 0.5 = partial / normalized equivalent
- 0 = wrong, missing, or hallucinated
- overall score = sum(field_scores) / total_fields

This is a standard and transparent way to compute extraction quality.

---

## For your question: “Does 1 mean the field matches exactly as in the ground truth?”

Yes — that is exactly what it should mean in the cleanest version.

A field gets:
- 1.0 if the extracted value matches the ground-truth value in a way the review treats as fully correct
- 0.5 if it is close but not exact, such as:
  - “Florida” vs “FL” if your normalization rule allows them to be equivalent
  - “$168,350,000” vs “168350000” after numeric normalization
  - a shortened phrase that still captures the correct meaning
- 0 if it is:
  - wrong
  - missing
  - invented
  - clearly unrelated

So the scoring is per field, not per document.

---

## Example

If a schema has 10 fields and the extracted output scores are:

- 8 fields = 1
- 1 field = 0.5
- 1 field = 0

Then:

- sum = 8 + 0.5 + 0 = 8.5
- overall = 8.5 / 10 = 0.85 = 85%

That is exactly the kind of metric you want.

---

## Important interpretation

This score is:
- not a model confidence score
- not a probability from the LLM
- it is a validation score against ground truth

That is the right thing to compute for your non-ACORD Azure Foundry extraction flow.

---

## Recommendation

Use this exact policy for the first implementation:

- Validate only one document type first
- Keep a gold-truth JSON for that type
- Compare each field
- Assign 1 / 0.5 / 0 per field
- Compute overall score = sum(field_scores) / total_fields
- Log the per-field mismatches so you know what failed

This gives you an objective, explainable, and auditable score without changing the production flow.
